# fre:ac - Tracks from a Disc You Own

fre:ac reads an audio CD in a drive you have, or works from files you already possess, and writes one track per file when you ask it to. Titles should be read before the rip, not repaired afterward by hunting another copy.

---

## Product Snapshot

Put in a disc you own. If fre:ac offers names, compare them with the booklet or with what you know the disc contains. A lookup can be wrong: two albums share a title. If the track count does not match, do not rip under those names. Type them or leave the job.

Choose a folder with room for the tracks and a format you can play. The disc is not erased by a normal rip. When the files exist, play the first and the last in an ordinary player. Keep the disc until that check is done. A protected disc that will not read is not a puzzle to break.

## Highlights

- A CD you own, in your drive
- Names you check against the disc
- One file per track in a folder you chose
- A format you can already play
- First and last track checked after the rip
- No store download and no lock removal

---

## Live Production

Rip one album you are allowed to copy for yourself. Do not queue a stack of discs you have not looked at. If the drive is loud or the read fails, stop. Clean the disc you own or try again later. Do not replace a failed track with a file from a search page.

A cue sheet is only for audio you already have the right to split. fre:ac will not create the missing music.

---

## Names Before the Write

Read every title and time. A compilation matched as a studio album will name every track wrong. Cancel and correct the list, or rip with names you type. The folder name should say which disc it was, so next month you still know.

---

## Setup Path

Prerequisites: A disc you own, a drive that can read it, and space for the tracks.

1. Install fre:ac and insert that disc.
2. Read the track list. Stop if it is the wrong album.
3. Pick an output folder and a format you can play.
4. Rip, then play the first and last files.
5. Keep the disc until those files are the right songs.

## Who Benefits

fre:ac fits a CD you own and want as files. It does not fit a disc you may not copy, a protected file that will not open, or a search for songs you do not have.

---

## Fixes

The names are wrong: do not keep that rip as labeled. Delete the bad files or rename from the booklet, and do not look up a pirate copy. The drive will not read: stop. The last track is cut off: rip that disc again from the disc you own. A cue has no audio: fre:ac cannot invent it.
